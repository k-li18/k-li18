## Hi, I'm Kevin

I build AI tools that turn a topic into a finished vertical video — no camera, no editing timeline, no footage to shoot.

### Faceless Reels

[**facelessreels.video**](https://facelessreels.video/) — type a topic, get a ready-to-post faceless video: AI script, voiceover, captions and music. The first video is free.

Each generator is its own pipeline with its own presets, prompts and render settings:

| Tool | What it makes |
| --- | --- |
| [Brainrot Video Generator](https://facelessreels.video/tools/brainrot-mov) | Character-driven brainrot clips with voices and burned-in captions |
| [Stickman Animation Generator](https://facelessreels.video/tools/stickman-animation) | Stickman animation from a plain script |
| [AI Explainer Video](https://facelessreels.video/tools/ai-explainer-video) | Doodle / whiteboard explainers for teaching a concept |
| [YouTube Automation](https://facelessreels.video/tools/youtube-automation) | Storytelling videos for faceless channels |
| [AI Video Script Generator](https://facelessreels.video/tools/ai-video-script-generator) | Hook, narration and a scene-by-scene breakdown |
| [Open Source Short](https://facelessreels.video/tools/open-source-short) | Shorts built from trending GitHub repositories |
| [MoneyPrinterTurbo Online](https://facelessreels.video/tools/moneyprinterturbo) | Hosted MoneyPrinterTurbo — nothing to install locally |
| [Facebook Video Downloader](https://facelessreels.video/tools/facebook-reels-downloader) | HD MP4 from Reels and posts |

Two more sites run on the same render pipeline with a different preset library:
[autober.net](https://autober.net/) and [facelessreels.studio](https://facelessreels.studio/).

### Stack

Next.js on Cloudflare Workers via OpenNext · Postgres + Drizzle · Better Auth · Stripe ·
a shared ffmpeg render service on Hetzner · 10 locales through next-intl.
